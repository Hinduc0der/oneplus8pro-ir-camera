# oneplus8pro-ir-camera — разблокировка скрытого ИК/цветофильтр-сенсора (cameraId 4)

> 🇬🇧 **[English version →](README.md)** · 🇷🇺 Русская версия (этот файл).

Разблокировать и снимать **5-Мп сенсором «цветной фильтр»** на OnePlus 8 Pro (IN2020) — это
четвёртая задняя камера, которую OnePlus продавал под маркой **«Photochrom»** и затем отключил
обновлением в 2020.

В репозитории — крошечное привилегированное приложение (**IRMono**) и **прошиваемый Magisk-модуль**,
который даёт приложению открыть этот сенсор напрямую (`cameraId 4`), показать живое превью,
сохранять кадры в полном разрешении **2592×1944** и **записывать видео**. В отличие от штатного «Photochrom» —
это подмешивание в реальном времени (RTB) к картинке **главного** сенсора, — здесь читается сам
отдельный модуль: со своим ракурсом и характерным сине-холодным false-color. ИК-светодиод пульта от
телевизора, невидимый глазу, ярко светится через него.

> Проверено на **OnePlus 8 Pro IN2020, китайская ColorOS 13.1.0.187** (сборка `IN2020_11.F.73`,
> Android 13). Железо сенсора одинаково на всех версиях 8 Pro, поэтому на глобальном OxygenOS, скорее
> всего, тоже заработает, но это **не проверялось** — см. [Совместимость](#совместимость).

## Почему нужно привилегированное приложение

С Android 10 лишние физические сенсоры многокамерного устройства скрыты за разрешением
`SYSTEM_CAMERA`. Обычное приложение при вызове `getCameraIdList()` видит только четыре «логических»
камеры (id `0–3`) и никогда не видит `cameraId 4`. `SYSTEM_CAMERA` — разрешение уровня
`signature|privileged`, поэтому единственный способ получить его обычному (не подписанному ключом
платформы) приложению — быть установленным как **привилегированное** (`/system/priv-app`) с записью
в allow-list. Ровно это и делает Magisk-модуль — без правки прошивки, полностью обратимо.

## Чем отличается от штатного «Photochrom»

Штатный «Photochrom» — это **RTB (подмешивание в реальном времени)**: съёмка всё время идёт на
**главном** 48-Мп сенсоре, а сверху подмешивается оттенок; геометрия, ракурс и EXIF — от главного
объектива. Этот проект открывает **отдельный** сенсор цветофильтра (`cameraId 4`) сам по себе — его
реальный кадр 2592×1944, его слегка смещённый ракурс и чистый сине-холодный false-color.

## Установка (рекомендуется: прошиваемый Magisk-модуль)

**Требования**
- OnePlus 8 Pro с **разблокированным загрузчиком** и **Magisk** (v20.4+).
- Возможность перезагрузки. ~20 КБ места.

**Шаги**
1. Скачать `IRMono-magisk-module-vX.Y.zip` со страницы [Releases](../../releases).
2. Magisk → **Модули** → **Установить из хранилища** → выбрать zip.
3. **Перезагрузить.** (Система сканирует `priv-app` и выдаёт `SYSTEM_CAMERA` только при загрузке.)
4. Открыть **«IR Camera»** из меню приложений. Нажать **Разрешить** на запрос доступа к камере.
5. Превью откроется на `cam 4` (метка слева вверху: `cam 4   2592×1944`).
   - **СНЯТЬ** — сохранить кадр в `DCIM/IRMono/`.
   - **ВИДЕО** — записать ролик в `DCIM/IRMono/` (повторное нажатие — стоп; звук с микрофона, если разрешить).
   - **СЕНСОР ▸** — пролистать остальные сенсоры.

**Удаление:** Magisk → Модули → выключить *IR Camera* (или удалить) → перезагрузка. Системный раздел
не трогается, overlay просто исчезает.

### Альтернатива: установка вручную через adb (без прошивки)

Если хочется разложить файлы руками (устройство рутовано, `adb` + `su` работают):

```sh
adb push IRMono.apk /sdcard/Download/IRMono.apk
adb push privapp-permissions-irmono.xml /sdcard/Download/

adb shell su -c '
  MOD=/data/adb/modules/irmono
  mkdir -p $MOD/system/priv-app/IRMono $MOD/system/etc/permissions
  cp /sdcard/Download/IRMono.apk $MOD/system/priv-app/IRMono/IRMono.apk
  cp /sdcard/Download/privapp-permissions-irmono.xml $MOD/system/etc/permissions/
  # module.prop
  printf "id=irmono\nname=IR Camera\nversion=1.0\nversionCode=1\nauthor=you\ndescription=IR camera\n" > $MOD/module.prop
  chown -R 0:0 $MOD
  chcon -R u:object_r:system_file:s0 $MOD/system
'
adb reboot
# после загрузки можно заранее выдать runtime-разрешение (иначе приложение само спросит при запуске):
adb shell su -c 'pm grant com.irmono.cam android.permission.CAMERA'
```

## Как это устроено

Две маленькие части:

**1. Allow-list** (`privapp-permissions-irmono.xml`, кладётся в `/system/etc/permissions/`):

```xml
<permissions>
    <privapp-permissions package="com.irmono.cam">
        <permission name="android.permission.SYSTEM_CAMERA"/>
    </privapp-permissions>
</permissions>
```

Поскольку APK лежит в `/system/priv-app`, PackageManager читает этот файл при загрузке и выдаёт
`SYSTEM_CAMERA` — после чего `getCameraIdList()` возвращает и скрытые сенсоры.

**2. Приложение** (`com.irmono.cam`, ~16 КБ, чистый Camera2, без зависимостей):
- `getCameraIdList()` теперь включает `4` (и остальные `SYSTEM_CAMERA`-id). Приложение предпочитает `cameraId 4`.
- Открывает его, запускает превью в `TextureView`, а по кнопке **СНЯТЬ** снимает JPEG в максимальном
  размере сенсора (2592×1944) через `ImageReader` и сохраняет через `MediaStore` в `DCIM/IRMono/`.

### Карта сенсоров (OnePlus 8 Pro, из логов инженерной камеры)

| cameraId | сенсор                           |
|---------:|----------------------------------|
| 0        | главный (48 Мп, Sony IMX689)     |
| 1        | фронтальный                      |
| 2        | ультраширокий                    |
| 3        | телефото                         |
| **4**    | **5 Мп цветофильтр / «Photochrom»** |

`cameraId 4` — тот самый сенсор, ради которого всё.

## Сборка из исходников

Приложение сознательно собирается только командными инструментами Android SDK (без Gradle).
Полный исходник — в [`app/`](app/): `MainActivity.java`, `AndroidManifest.xml`.

Вкратце (JDK 17, SDK build-tools 34/35, `android.jar` от platform 35):

```
aapt2 link  -o base.apk --manifest AndroidManifest.xml -I android.jar --java gen
javac --release 11 -classpath android.jar -d classes <sources>
d8 --output . classes/**/*.class
# добавить classes.dex в base.apk, затем:
zipalign -f 4 base.apk irmono-aligned.apk
apksigner sign --ks debug.keystore ... irmono-aligned.apk   # -> IRMono.apk
```

Точные команды и две грабли (32-битный `JAVA_HOME` ломает `d8`; `-bootclasspath` против `--release`) —
в [`app/BUILD.md`](app/BUILD.md).

## Совместимость

- **Подтверждено:** OnePlus 8 Pro **IN2020**, ColorOS 13.1.0.187 CN.
- **Вероятно, но не проверено:** остальные SKU 8 Pro (IN2010/IN2015/IN2017/IN2019) и глобальный
  OxygenOS — то же железо, тот же Camera2 HAL. Карта id сенсоров может отличаться; если `cameraId 4`
  у тебя окажется не цветофильтром, пролистай кнопкой **СЕНСОР ▸** до сине-холодной картинки и
  запомни, какой это id.
- **Не поможет** телефонам без этого четвёртого сенсора (например OnePlus 8, 8T, Nord).

## Предостережения

- Нужен разблокированный загрузчик + root. Разблокировка стирает устройство; root снимает гарантию.
- Полностью обратимо: модуль добавляет только overlay. Выключить в Magisk и перезагрузиться — и всё
  как было.
- OTA-обновление может сломать root — перед обновлением верни стоковый `boot.img`, потом перепатчи.
- Приложение подписано одноразовым отладочным ключом. Если не хочешь доверять готовому APK — пересобери
  из исходников, ровно для этого они здесь.
